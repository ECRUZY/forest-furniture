Доступ к админке

Делается один раз. На выходе будет личная ссылка: она открывает админку только вместе с вашим паролем.

  1. Откройте создание токена GitHub.
  2. Repository access → Only select repositories → репозиторий сайта.
  3. Permissions → Contents → Read and write. Срок — до года.
  4. Нажмите Generate token, скопируйте его сюда.

Доступ проверен

Ваша личная ссылка — сохраните её в закладки или в «Избранное» Telegram. Никому не пересылайте вместе с паролем.
