# Forest Furniture — каталог

Статичный сайт без сборки: код на GitHub, публикация через Vercel. Локально открывается двойным кликом по `index.html`.

## Структура

```
index.html                 разметка страницы
404.html                   ссылки вида …/kitchens/12/ открывают модель, даже если превью ещё не создано
admin.html                 админка (вход по личной ссылке + пароль)
assets/css/main.css        все стили (mobile-first, светлая и тёмная тема)
assets/js/app.js           логика: фильтры, поиск, карточка модели, галерея, заявки
assets/js/admin.js         логика админки (сохранение через GitHub API)
assets/img/                логотип, QR-коды WhatsApp/Telegram, иконки сайта
data/config.js             контакты и список разделов каталога
data/kitchens.js           модели кухонь (138 шт.)
photos/kitchens/           оригиналы фото: <номер>_<n>.jpg
photos/kitchens/thumbs/    лёгкие превью для карточек (делаются скриптом)
kitchens/<номер>/          страницы-превью для мессенджеров (создаёт админка)
tools/make-thumbs.sh       создаёт превью для фото, добавленных вручную
tools/make-share-pages.py  создаёт страницы-превью для мессенджеров без админки
vercel.json                настройки Vercel (админка не индексируется, данные не кэшируются)
```

## Нумерация

Номер модели (`id`) — главный идентификатор, он:

- показан на карточке и в окне модели («№ 48»);
- совпадает с именем фото: `photos/kitchens/48_1.jpg`, `48_2.jpg`, …;
- уходит в сообщение WhatsApp/Telegram, чтобы менеджер сразу видел, о какой кухне речь;
- работает в поиске: ввод `48` или `№48` открывает ровно эту модель;
- даёт ссылку на модель: `…/kitchens/48/` (карточка для мессенджеров) и `…/#kitchens/48`.

Номера идут подряд с 1 по 138. Новой модели даём следующий свободный номер (139, 140, …).
Номер удалённой модели не переиспользуем, чтобы старые ссылки и переписки не начали указывать на другую кухню.

## Публикация: GitHub + Vercel

1. Создайте на GitHub репозиторий (например, `forest-furniture`) и загрузите файлы через
   **Add file → Upload files**. За один раз GitHub принимает до 100 файлов, поэтому грузите
   частями. Порядок — в файле `КАК-ЗАГРУЖАТЬ.txt` в папке с порциями.
2. На [vercel.com](https://vercel.com/new) → **Add New → Project** → выберите этот репозиторий.
   Framework Preset: **Other**, Build Command и Output Directory оставьте пустыми → **Deploy**.
3. Основной адрес сайта — в Vercel → проект → **Domains** (вида `forest-furniture.vercel.app`).
   Этой ссылкой и делитесь. Ссылки отдельных сборок (`…-abc123-….vercel.app`) временные и обычно
   закрыты защитой Vercel — не используйте их.
4. Дальше любое изменение в репозитории (в том числе из админки) Vercel публикует сам за 20–60 секунд.

`vercel.json` закрывает админку от поисковиков и отключает кэш данных, чтобы правки появлялись сразу.
Без него сайт тоже работает, но лучше загрузить.

## Админка (добавление моделей с телефона)

`admin.html` — добавление, правка и удаление моделей, загрузка и порядок фото.
Ссылок на неё на сайте нет, поисковики её не индексируют.

Сайт статичный, поэтому админка сохраняет изменения коммитом прямо в GitHub-репозиторий,
а Vercel сразу публикует новую версию — изменения видны примерно через минуту.

**Первая настройка (один раз):**

1. Опубликуйте сайт (раздел выше).
2. Откройте `https://ваш-сайт.vercel.app/admin.html` — именно по основному адресу.
3. Создайте токен GitHub (инструкция прямо на экране): доступ только к репозиторию сайта,
   `Contents: Read and write`.
4. Укажите основной адрес сайта, репозиторий, токен и придумайте пароль. Админка проверит доступ
   и выдаст **личную ссылку** `admin.html#key=…`.
5. В меню админки нажмите **«Обновить превью-ссылки»** — появятся карточки для мессенджеров.

Личная ссылка — это токен, зашифрованный вашим паролем (AES-256, PBKDF2). Без пароля она бесполезна,
а часть после `#` браузер не отправляет на сервер. Храните ссылку в закладках или в «Избранном» Telegram.
Если ссылка утекла, отзовите токен на GitHub и создайте новую ссылку (меню → «Новая личная ссылка»).

Фото сжимаются прямо в браузере: оригинал до 1600px, превью до 800px. Скрипт `make-thumbs.sh` для них не нужен.
Номер новой модели — следующий свободный. Удалённый номер не переиспользуется.

## Карточки в WhatsApp и Telegram

Кнопки «Узнать цену» и Telegram отправляют менеджеру короткое сообщение со ссылкой вида
`https://ваш-сайт/kitchens/48/`. У этой страницы свои og-теги (фото, название, размер, цвет),
поэтому мессенджер показывает её **карточкой**. Человек, нажавший на карточку, попадает в каталог
сразу на эту модель.

Страницы-превью создаёт админка: при каждом сохранении модели — для этой модели, а пункт меню
**«Обновить превью-ссылки»** делает их сразу для всех. Сделайте это один раз после публикации сайта.
Без админки их можно сделать на компьютере: `python3 tools/make-share-pages.py https://адрес-сайта/`
и загрузить появившуюся папку `kitchens/` в корень репозитория.
Карточки работают только на опубликованном сайте (на `localhost` мессенджеры их не увидят).
Адрес для карточек берётся из личной ссылки админки (поле «Основной адрес сайта»). Если подключите
свой домен, создайте новую личную ссылку с новым адресом и снова нажмите «Обновить превью-ссылки».

## Как добавить кухню вручную (без админки)

1. Положите фото в `photos/kitchens/` с именами `139_1.jpg`, `139_2.jpg`, …
2. Запустите в терминале из папки проекта: `sh tools/make-thumbs.sh`.
3. Допишите строку в конец `data/kitchens.js`:
   ```js
   {"id": 139, "name": "Название", "type": "Прямая", "producer": "Фабрика (Город)", "colors": ["Белый"], "sizes": ["300"], "desc": "В: 240, Г: 60, фасад МДФ", "photos": 2},
   ```
   - `type`: `"Прямая"` или `"Угловая"`;
   - `sizes`: варианты размера, у угловых `"395×275"`;
   - `colors`: варианты цвета (клиент выбирает один), можно `[]`;
   - `desc`: через запятую; `В:` показывается как высота, `Г:` как глубина, остальное идёт списком «Комплектация»;
   - `photos`: сколько фото у модели.

## Новый раздел (шкафы, спальни…)

1. Создайте `data/wardrobes.js` по образцу кухонь (`window.CATALOG.wardrobes = [...]`).
2. Фото положите в `photos/wardrobes/` и запустите `sh tools/make-thumbs.sh`.
3. Подключите файл в `index.html` рядом с `data/kitchens.js`.
4. Добавьте раздел в `categories` в `data/config.js` (там есть закомментированный пример).

Вкладка раздела, фильтры и счётчики появятся сами.

## Контакты

Телефон, WhatsApp и Telegram меняются в одном месте: `data/config.js`.
